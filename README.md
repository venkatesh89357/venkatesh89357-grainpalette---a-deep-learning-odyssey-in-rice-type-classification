🌾 GrainPalette – Rice Type Classification

GrainPalette is a deep learning–based system designed to classify different varieties of rice grains using transfer learning (MobileNetv4) and Convolutional Neural Networks (CNNs). The goal of this project is to provide an efficient and accurate way to identify rice types from images, which can support agricultural research, food quality assessment, and automation in the grain industry.

🚀 Features

--> Rice type classification using state-of-the-art deep learning models.

--> Transfer learning with MobileNetv4 for high accuracy and reduced training time.

--> Preprocessing pipeline for image enhancement and normalization.

--> Custom CNN layers fine-tuned for rice grain features.

--> Model evaluation with accuracy, precision, recall, and F1-score metrics.

🛠️ Tech Stack

--> Python

--> TensorFlow / Keras

--> NumPy, Pandas, Matplotlib, OpenCV

--> Jupyter Notebook (for experiments and prototyping)
